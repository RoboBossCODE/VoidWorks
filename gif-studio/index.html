GIF//STUDIO QUICK START

Import images or a video, then arrange frames in the timeline. The editor renders your animation exactly as it will appear in the GIF.

  1. Add media. Choose images, or select a video, pick a time range and extract frames.
  2. Edit the animation. Rearrange frames by dragging or using the arrow buttons; set timing and FPS, crop, apply effects and add captions.
  3. Export. Choose your palette and optional dithering in the Export tab, then download the animated GIF.

Tip: Click TRY THE DEMO for a built-in animation. On desktop, Space plays or pauses; Delete removes the selected frame when you're not editing text.

Your media is never uploaded. Projects can be downloaded as JSON files and re-opened later.
